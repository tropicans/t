## Phase Goal

**As a** microsite owner, **I want to** reorder my microsite links with drag and drop or chevrons, **so that** my public microsite displays active links in that prioritized order.

<objective>

Purpose: provide a safe, accessible, and responsive link prioritizing UX without external dependencies.
Output: verification script, updated reorder action, and updated drag-and-accessible editor interface.
</objective>

## STRIDE Threat Register

|-----------|----------|-----------|----------|-------------|-----------------|

| T-02-02 | Tampering | DB writes | medium | mitigate | Run all updates inside a `prisma.$transaction` block to guarantee atomic writes. |
| T-02-03 | Denial of service | page loading | low | mitigate | Skipped server action call if index sequence is identical to current state. |
