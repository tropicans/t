# Plan 16-01: RBAC & Audit Data Model, Migration & Auth Synchronization

## Goal
Menambahkan enum `Role` dan model `AuditLog` ke Prisma schema, meng-generate Prisma client, meng-update TypeScript types NextAuth, dan menyinkronkan penetapan role pada NextAuth session & JWT callbacks.

## Tasks

### Task 1: Update Prisma Schema & Generate Client
- Edit `prisma/schema.prisma`:
  - Tambahkan `enum Role { ADMIN OPERATOR MEMBER }`.
  - Tambahkan field `role Role @default(MEMBER)` pada model `User`.
  - Tambahkan model `AuditLog`:
    ```prisma
    model AuditLog {
      id         String   @id @default(cuid())
      userId     String?
      user       User?    @relation(fields: [userId], references: [id], onDelete: SetNull)
      userEmail  String?
      userName   String?
      action     String
      entity     String
      entityId   String?
      details    Json?
      ipAddress  String?
      createdAt  DateTime @default(now())

      @@index([userId])
      @@index([action])
      @@index([entity])
      @@index([createdAt])
    }
    ```
- Jalankan `npx prisma generate` untuk memperbarui `@prisma/client`.

### Task 2: Update TypeScript NextAuth Declarations
- Edit `src/types/next-auth.d.ts`:
  - Tambahkan `role?: "ADMIN" | "OPERATOR" | "MEMBER"` pada interface `User`, `Session["user"]`, dan `JWT`.

### Task 3: Update Auth Synchronization in `src/lib/auth.ts` and `src/lib/admin.ts`
- Di `src/lib/auth.ts`:
  - Saat `authorizeUserSignIn` (baik untuk existing user maupun bootstrap superadmin):
    - Tentukan role berdasarkan prioritas: `ALLOWED_EMAILS` -> `ADMIN`, `GLOBAL_DASHBOARD_VIEWER_EMAIL` -> `OPERATOR`, default -> `MEMBER`.
    - Upsert atau update `User.role` di database jika belum diset atau ada di bootstrap list.
  - Di `callbacks.jwt`:
    - Ambil `role` dari database `dbUser.role` dan simpan ke `token.role`.
    - Tetapkan `token.isAdmin = token.role === "ADMIN" || isUserAdmin(email)`.
    - Tetapkan `token.isOperator = token.role === "OPERATOR" || isGlobalDashboardViewer(email)`.
  - Di `callbacks.session`:
    - Teruskan `session.user.role = token.role as any`.
    - Teruskan `session.user.isAdmin = Boolean(token.isAdmin)`.
    - Teruskan `session.user.isOperator = Boolean(token.isOperator)`.
- Di `src/lib/admin.ts`:
  - Tambahkan helper `isUserOperator(email?: string | null)` dan `getUserRole(email?: string | null)`.

### Task 4: Automated Testing & Verification
- Tulis unit test di `src/lib/auth.test.ts` dan `src/lib/admin.test.ts` untuk memverifikasi role determination, sinkronisasi role, dan token decorating.
- Jalankan `npx vitest run` dan `npx tsc --noEmit`.

## Verification Criteria
- [x] Schema Prisma memiliki `enum Role` dan model `AuditLog`.
- [x] NextAuth types memiliki `role`.
- [x] Vitest tests untuk auth & admin helper lulus 100%.
