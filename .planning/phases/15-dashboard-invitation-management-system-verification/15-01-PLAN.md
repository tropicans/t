# Plan 15-01: Dashboard Invitation Management & System Verification

## Objective
Build a comprehensive Invitation Management interface in the dashboard with Claude editorial styling allowing authenticated users to create new invitation links (open or email-specific, custom quota, and expiration periods), inspect active and past invitations with real-time status and claimed users, quickly copy invite URLs with clipboard feedback, and revoke active invitations. Verify the implementation with automated Vitest tests and full system verification (clean TypeScript compile and production build).

## Proposed Changes

### 1. Data Access Extension (`ADMIN-01`)
- **File:** `src/lib/invitations.ts`
- Add `getUserInvitations(userId: string, isGlobalViewer?: boolean)`:
  - Queries `prisma.invitation.findMany`.
  - Filters by `{ invitedById: userId }` unless `isGlobalViewer` is true.
  - Includes `claimedUsers: { select: { id: true, name: true, email: true, image: true, createdAt: true } }` and `invitedBy: { select: { id: true, name: true, email: true } }`.
  - Orders by `createdAt: 'desc'`.

### 2. Invitation Server Actions (`ADMIN-01`)
- **File:** `src/app/actions/invitations.ts` [NEW]
- Provide:
  - `createInvitationAction(data: { email?: string; maxUses?: number; expiresInDays?: number | null })`:
    - Validates authenticated session via `getServerSession(authOptions)` and fetches DB user.
    - Sanitizes and validates optional `email` format.
    - Parses and constrains `maxUses` (integer >= 1).
    - Calculates `expiresAt` based on `expiresInDays` (or null for no expiration).
    - Calls `createInvitation` from `src/lib/invitations.ts`.
    - Revalidates `/dashboard/invitations`.
    - Returns `{ success: true, invitation: { ... } }`.
  - `revokeInvitationAction(invitationId: string)`:
    - Validates authenticated session and fetches DB user.
    - Checks ownership or permissions.
    - Calls `revokeInvitation(invitationId, user.id)`.
    - Revalidates `/dashboard/invitations`.
    - Returns `{ success: true }`.

### 3. Dashboard Invitation Management UI (`ADMIN-01`)
- **File:** `src/app/dashboard/invitations/page.tsx` [NEW]

    - Subtitle: "Buat tautan undangan untuk mengajak pengguna baru bergabung ke platform."
    - Stat badges/counters: Total Undangan, Undangan Aktif, Total Pengguna Bergabung.
  - Embeds `InvitationForm` and `InvitationList`.

- **File:** `src/app/dashboard/invitations/invitation-form.tsx` [NEW]
  - Client Component with warm editorial styling:
    - Mode toggle between "Tautan Terbuka" (Open) and "Khusus Email" (Email-restricted).
    - Input for target email with live validation (shown only in email-restricted mode).
    - Max uses selector (1, 5, 10, 25, atau kustom).
    - Expiration selector (24 Jam, 7 Hari, 30 Hari, Tanpa Batas).

    - Generated link modal / callout card with full invite URL and a one-click "Salin Link" button with copied toast/feedback.

- **File:** `src/app/dashboard/invitations/invitation-list.tsx` [NEW]

    - Filter tabs: Semua, Aktif, Selesai / Kedaluwarsa, Dicabut.
