# Plan 18-01: Dashboard UI Role Management & Audit Trail Timeline

## Goal
Menyediakan fitur visual bagi Admin untuk mengelola hak akses (Role: ADMIN, OPERATOR, MEMBER) pada pengguna terdaftar, serta menambahkan tab Audit Trail untuk memantau linimasa aktivitas mutasi sistem ("siapa melakukan apa").

## Tasks

### Task 1: Server Action for Role Management
- Buat `src/app/actions/users.ts`:
  - `updateUserRoleAction({ userId: string, newRole: "ADMIN" | "OPERATOR" | "MEMBER" })`
  - Validasi otentikasi & izin admin (`isUserAdmin(session.user.email, currentUser.role)`).
  - Validasi self-lockout: cegah admin mengubah role dirinya sendiri.
  - Update `prisma.user.update`.
  - Catat log audit `USER_ROLE_UPDATE` via `logAuditEvent()`.
  - Revalidate cache dashboard.

### Task 2: Update UserList Component
- Edit `src/app/dashboard/invitations/user-list.tsx`:
  - Tambahkan prop `currentUserId: string`.
  - Tambahkan indikator role lengkap (`ADMIN`, `OPERATOR`, `MEMBER`).
  - Tambahkan dropdown pemilihan role dengan feedback interaktif (loading state & error toast).
  - Nonaktifkan pemilihan role untuk diri sendiri dengan keterangan `(Akun Anda)`.
  - Perbarui filter role tabs untuk menyertakan `OPERATOR`.

### Task 3: Create Audit Trail Component & Update AdminTabs
- Buat `src/app/dashboard/invitations/audit-trail-list.tsx`:
  - Tampilkan linimasa aktivitas dengan kolom/card: Waktu, Pelaku (Nama & Email), Aksi (badge warna-warni), Entitas, dan Detail.
  - Sediakan pencarian teks dan filter berdasarkan aksi/entitas.
- Edit `src/app/dashboard/invitations/admin-tabs.tsx`:
  - Tambahkan tab ke-3: "Audit Trail" dengan icon linimasa / Activity.
  - Tambahkan counter log audit.
- Edit `src/app/dashboard/invitations/page.tsx`:
  - Ambil log audit terbaru via `getRecentAuditLogs({ limit: 100 })`.
  - Operkan `currentUserId={dbUser.id}` ke `UserList`.
  - Pasang `auditTrailContent={<AuditTrailList initialLogs={auditLogs} />}`.

### Task 4: Unit Testing & Full Verification
- Buat `src/app/actions/users.test.ts`:
  - Test validasi unauthenticated.
  - Test validasi non-admin rejection.
  - Test proteksi self-lockout.
  - Test update role berhasil & log audit tercatat.
- Jalankan Vitest (`npx vitest run`), `npx tsc --noEmit`, dan `npm run build`.

## Verification Criteria
- [x] Admin dapat mengubah role pengguna lain menjadi ADMIN, OPERATOR, atau MEMBER.
- [x] Admin tidak dapat mendemosi dirinya sendiri (proteksi lockout).
- [x] Linimasa Audit Trail menampilkan aktivitas mutasi dengan timestamp, pelaku, dan rincian.
- [x] Seluruh unit test lulus dan build aplikasi berhasil tanpa error.
