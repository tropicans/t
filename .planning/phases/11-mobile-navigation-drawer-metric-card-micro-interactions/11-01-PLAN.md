# Plan 11-01: Mobile Navigation Drawer & Metric Card Micro-interactions

## Goal

Enhance the dashboard mobile UX by adding a slide-out navigation drawer in `src/app/dashboard/layout.tsx` and improve visual polish on `/dashboard` stat cards with subtle hover lifts, cohesive iconography, and WCAG AA contrast compliant action links.

## Proposed Changes

### 1. `src/app/dashboard/layout.tsx`
- Add mobile navigation state (`isMobileNavOpen`).
- Add hamburger menu trigger button and close button (`Menu`, `X` from `lucide-react`) with accessible ARIA attributes.
- Add slide-out drawer panel with backdrop overlay, smooth transitions, ESC key handler, and auto-dismiss on route change.
- Replicate full navigation items, active pill indicators, user avatar profile, and sign-out action in the mobile drawer.

### 2. `src/app/dashboard/page.tsx`
- Enhance stat cards with `transition-all duration-200 hover:-translate-y-0.5 hover:shadow-xs hover:border-primary/30`.
- Add harmonized icon wrappers (`w-8 h-8 rounded-lg bg-primary/10 flex items-center justify-center text-primary`).
- Update action link colors to `text-terracotta-active dark:text-primary hover:underline` ensuring WCAG AA contrast ratio (≥ 4.5:1) for small text.

## Verification
- `npx vitest run` - all test suites pass.
- `npx tsc --noEmit` - clean TypeScript compilation.
