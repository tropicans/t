# Plan 12-01: Dashboard Recent Activity, Onboarding & System Verification

## Goal

Add a recent activity section and an editorial onboarding state for new users on `src/app/dashboard/page.tsx`, and run end-to-end automated unit tests and TypeScript compiler verification.

## Proposed Changes

### 1. `src/app/dashboard/page.tsx`
- Query top 3 recent microsites and top 3 recent short links in parallel using `Promise.all`.
- When both counts are 0, render an editorial onboarding card with warm terracotta accents and clear CTA buttons.
- When items exist, render structured Recent Activity cards for Microsites and Short Links with direct links to manage/view.
- Use `formatDistanceToNow` or readable date format for activity timestamps.

### 2. Verification
- `npx vitest run`: verify all test suites pass.
- `npx tsc --noEmit`: zero TypeScript errors.
- `npm run build`: ensure production build compiles cleanly.
