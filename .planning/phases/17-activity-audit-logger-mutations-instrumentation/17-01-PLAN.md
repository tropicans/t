# Plan 17-01: Activity Audit Logger Engine & Mutations Instrumentation

## Goal
Membuat helper server-side `logAuditEvent()` di `src/lib/audit.ts` dan menginstrumentasikannya pada seluruh server actions mutasi (Short Links, Microsites, Invitations) agar setiap tindakan "siapa melakukan apa" tersimpan di database `AuditLog`.

## Tasks

### Task 1: Create Audit Logger Engine
- Buat `src/lib/audit.ts`:
  - Definisikan tipe input `LogAuditEventInput`:
    - `userId?: string | null`
    - `userEmail?: string | null`
    - `userName?: string | null`
    - `action: string`
    - `entity: string`
    - `entityId?: string | null`
    - `details?: Record<string, any> | null`
    - `ipAddress?: string | null`
  - Implementasikan fungsi `logAuditEvent(input: LogAuditEventInput): Promise<AuditLog | null>`.
  - Implementasikan query helper `getRecentAuditLogs({ limit, action, entity })`.

### Task 2: Instrument Short Link Actions
- Edit `src/app/actions/short.ts`:
  - `createShortLink`: Catat `SHORT_LINK_CREATE` dengan data `{ shortCode, originalUrl }`.
  - `updateShortLink`: Catat `SHORT_LINK_UPDATE` dengan data perubahan.
  - `deleteShortLink`: Catat `SHORT_LINK_DELETE` dengan data `{ shortCode }`.
  - Pastikan permission boundaries: hanya pembuat atau ADMIN yang dapat update/delete.

### Task 3: Instrument Microsite Actions
- Edit `src/app/actions/microsite.ts`:
  - `createMicrosite`: Catat `MICROSITE_CREATE` dengan data `{ slug, title }`.
  - `updateMicrosite`: Catat `MICROSITE_UPDATE` dengan data perubahan.
  - `deleteMicrosite`: Catat `MICROSITE_DELETE` dengan data `{ slug }`.
  - `saveReorderedLinks`: Catat `MICROSITE_REORDER` dengan data `{ count }`.
  - Pastikan `canManageAllMicrosites` hanya untuk `ADMIN`, bukan `OPERATOR`.

### Task 4: Instrument Invitation Actions
- Edit `src/app/actions/invitations.ts`:
  - `createInvitationAction`: Catat `INVITATION_CREATE` dengan data `{ token, maxUses, targetEmail }`.
  - `revokeInvitationAction`: Catat `INVITATION_REVOKE` dengan data `{ token }`.
  - Pastikan hanya `ADMIN` yang bisa menerbitkan / mencabut undangan.

### Task 5: Testing & Verification
- Buat unit test `src/lib/audit.test.ts` untuk menguji `logAuditEvent` dan query helper.
- Update test cases yang relevan di `src/app/actions/*.test.ts`.
- Jalankan `npx vitest run` dan `npx tsc --noEmit`.

## Verification Criteria
- [x] Helper `logAuditEvent` dapat menyimpan record ke tabel `AuditLog`.
- [x] Aksi CRUD short link, microsite, dan invitation memanggil `logAuditEvent`.
- [x] Semua unit tests lulus 100%.
